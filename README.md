### 🚀 О себе

Я увлекаюсь созданием **собственных операционных систем**, легковесных дистрибутивов Linux и экспериментами с AI на уровне ядра и пользовательского пространства.  
Также пишу небольшие игры и инструменты.

Люблю:
- Arch / Artix / runit / systemd
- Низкоуровневое программирование (C, C++, Go, Python)
- GNOME / XFCE кастомизацию
- Геймдев (Three.js, flow fields, FSM)
